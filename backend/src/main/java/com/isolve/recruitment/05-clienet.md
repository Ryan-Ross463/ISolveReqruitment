# Client Module

## Purpose

The Client module manages companies that require recruitment services.

---

## Responsibilities

- Store company information
- Manage client relationships
- Maintain client contacts
- Track recruitment requirements

---

## Owns

- Client profile
- Company information
- Client contacts

---

## Does Not Own

The Client module does not manage:

- Candidate profiles
- Vacancies
- Applications
- Interviews

---

## Main Entities

### Client

Represents an organisation using ISolve services.

Contains:

- Company name
- Industry
- Contact details

---

## Relationships

Client creates:

Vacancies

---

## Communicates With

- Identity Module
- Vacancy Module
- Placement Module

---

## Future Features

- Client portal
- Client reporting
- Recruitment analytics
